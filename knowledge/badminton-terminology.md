# 羽球分析用語索引

本文件是供檢索的術語參考，不是統計資料或執行規則。使用者對分析範圍、空間對象、分類或門檻的明確定義優先。場區對照已確認；其他用語是否具有可操作定義，見各術語說明。未核准的研究性門檻或推論性 proxy 不能僅從術語名稱或現有事件欄位推定，也不能將 proxy 說成真實戰術意圖。

## 場區對照

1–24 為場內前／中／後場；25–32 是正式代碼中的出界區，不屬前／中／後場。33 是未定義落點，既不是正式場區，也不是出界區。

| 用語 | 對照區碼 |
|---|---|
| 前場 | 17–24 |
| 中場 | 5–16 |
| 後場 | 1–4 |
| 前中後場 | 後場 1–4；中場 5–16；前場 17–24 |
| 前後場 | 前場 17–24；後場 1–4 |
| 邊線附近 | A 欄 1、5、9、13、17、21；D 欄 4、8、12、16、20、24 |

資料包含 `landing_area`（落點）及 `player_location_area`（擊球者位置）這兩種空間欄位。空間對照本身不決定問題指的是哪個位置；欄位依問題中的空間對象選擇。其他空間欄位需先確認資料欄位定義。

## 目前可確認的分析邊界

- `getpoint_player` 記錄回合得分者，且只出現在終局事件；`win_reason` 與 `lose_reason` 是終局原因欄位。回合結果不等同於特定戰術意圖。
- 比分欄位的語意未確認為事件發生前或發生後快照；比分欄位不構成可直接執行的預設。
- 「四角拉吊」不能由區碼直接證明策略意圖；「被動救球」不能由一般事件欄位直接證明姿勢或被動狀態。
- 門檻、複合球種、連續球種事件及比賽階段都沒有預設值；需依問題明確指定。
