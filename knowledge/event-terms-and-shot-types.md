# 羽球逐拍名詞與球種

## 資料單位與欄位

資料每列代表一次實際擊球事件，不是比分快照或局末標記。階層為 `match_id → set → rally → ball_round`，事件鍵為 `(match_id, set, rally, ball_round)`。`rally_id` 識別回合；辨識回合時需搭配 `match_id` 與 `set`。`ball_round` 是回合內擊球序號，從 1 開始嚴格遞增。

事件數以擊球事件列為單位；回合數以唯一回合為單位，常用組合為 `(match_id, set, rally_id)`。事件數與回合數不是可互換的樣本單位。

| 欄位 | 名詞 | 欄位意義 |
|---|---|---|
| `match_id` | 比賽識別 | 識別一場比賽。 |
| `set` | 局數 | 比賽中的局；此資料集的局數為 1 至 3。 |
| `rally` | 局內回合序號 | 每局的回合序號，需與比賽及局數一併辨識。 |
| `rally_id` | 回合識別 | 識別一個回合，需搭配比賽與局數辨識。 |
| `ball_round` | 回合內擊球序號 | 發球為第 1 拍，其後依回合內擊球順序遞增。 |
| `player` | 擊球者 | 此擊球事件的擊球者標準名稱。 |
| `opponent` | 對手 | 此事件中擊球者的對手。 |
| `type` | 球種 | 此擊球事件記錄的球種名稱，使用下表所列中文名稱。 |
| `getpoint_player` | 回合得分者 | 每個回合恰有一位得分者，只記錄於終局事件；非終局事件的欄位值為空字串 `""`（不是 JSON null），表示回合尚未結束。 |
| `win_reason` | 得分原因 | 僅終局事件有意義；非終局事件或不適用時欄位值為空字串 `""`（不是 JSON null）。 |
| `lose_reason` | 失分原因 | 僅終局事件有意義；非終局事件或不適用時欄位值為空字串 `""`（不是 JSON null）。 |
| `landing_area` | 落點區域代碼 | 1–32 是正式區域代碼；33 表示未定義落點。 |
| `player_location_area` | 擊球者位置區域代碼 | 正式場區代碼為 1–32，不含 33。 |

`getpoint_player == ""` 不是得分者，也不代表擊球者失分；它表示該筆事件尚未結束回合。空字串是欄位原值，分析端應在臨時篩選結果中明確辨識，不應將原始事件改成 JSON null。

## 得失分名詞

- **得分者**：`getpoint_player` 所記錄的回合獲分球員。
- **未結束回合的標記**：`getpoint_player == ""` 表示非終局事件；不能將它當作缺失的 JSON null 或任何球員的得分結果。
- **主動得分（Active Win）**：終局事件的擊球者 `player` 與 `getpoint_player` 相同。
- **失分**：該回合得分者是此球員的對手；此結果本身不指出得分原因。
- **失誤／失分原因**：資料原因欄位 `lose_reason`；若欄位為空，`getpoint_player` 只標示得分者，不提供具體原因。
- **主動得分球種比例**：分子為指定球種的主動得分事件數，分母為同範圍該球員的主動得分事件數。
- **球種佔總得分比例**：分子限指定球員 P 本人在終局擊出球種 T，分母是 P 所有得分回合（包含對手失誤送分）；只有明確問主動得分內的比例才以 P 的主動得分數作分母。
